# 🧠💻 C++ Full Course

Welcome to my C++ Full Course repository! 🎉 This is a collection of topic-based C++ examples and mini projects created while learning the language. The numbered folders make it easy to follow the course in order, review a concept, and practice by running the code.

## 🚀 About This Repository

This repository contains:

- 📘 Examples covering C++ fundamentals and object-oriented programming
- 🧩 Small practice programs and console games
- 💻 Individual source files that demonstrate specific concepts
- 📂 Numbered topic folders arranged in learning order

## 📂 Repository Structure

```text
Cplusplus-Full-Course/
├── 01.Variables/

├── 03.Name Space/
├── 04.Typedef and Type aliases/
├── 05.Arithmetic operators/
├── ...
├── 60.Inheritance/

```

Each numbered folder contains one or more source files for that topic. Some folders have multiple examples, so choose a specific `.cpp` or `.cc` file to compile.

## 🛠️ Topics Covered

- Variables, constants, namespaces, and type aliases
- Operators, input, conditionals, and type conversion
- Loops, arrays, strings, and functions
- Random numbers and practice projects, including calculators and games
- Pointers, memory addresses, and dynamic memory
- Recursion, function templates, structs, and enums
- Object-oriented programming, constructors, getters and setters, and inheritance

The numbered folders contain the full topic sequence, from **01. Variables** through **60. Inheritance**.

## ▶️ How to Run the Programs

### Prerequisites

- Git
- A C++ compiler such as GCC (`g++`), MinGW-w64, or another compiler that supports your system
- A terminal such as Git Bash on Windows

### Clone the repository

```bash
git clone https://github.com/Aiyman-Misbah/Cplusplus-Full-Course.git
cd Cplusplus-Full-Course
```

### Compile and run an example

For example, to compile the variables example:

```bash
g++ "01.Variables/Datatype.cpp" -o example
./example
```

Replace the source-file path with the `.cpp` or `.cc` file you want to try. On Windows, the compiled program may also be run as:

```bash
./example.exe
```

Some examples ask for input in the terminal. Each source file is an independent practice example unless stated otherwise.

## 📚 Learning Tip

Start with the lowest-numbered topic and work through the folders in order. Read the source code, compile it, try it, and then change the code to see what happens.
